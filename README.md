# MOT-UK

This repository contains **MOTMate UK**, a local MVP web app for checking UK vehicle MOT history and buying/selling used vehicles.

The actual project lives in [`motmate-uk/`](./motmate-uk/).

## Quick start

```bash
cd motmate-uk
npm run install:all
npm run dev
```

Then open:

- Frontend: http://localhost:5173
- Backend health: http://localhost:3001/api/health

See [`motmate-uk/README.md`](./motmate-uk/README.md) for full setup, features, testing instructions and how to switch from mock MOT data to the real DVSA API.
